# Research Sources Registry (RS-NNN)

Every source consulted on the open web is logged here once, with a stable `RS` id
and its **URL**, so any claim in a finding or report resolves back to a real,
re-findable page. Read before creating (next free `RS` id); update as each source
is consulted. No claim without a source (`.claude/rules/evidence-and-figures.md`).

IDs are never reused or deleted — mark a retired source `Deprecated` with a reason.
